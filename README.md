# NusaLib
NusaLib is a web-based digital library platform developed using Node.JS, Express, and MariaDB. It aims to provide modern and accessible management system with support for authentication, digital book organisaztion, and future online reading features.
## The Story
The Story behind of NusaLib was back from 2025 where I was learning Node.JS and website development (both front-end and back-end), the first name of this project was my middle first school (SMPK Ignatius Slamet Riyadi Digital Library) as a concept for digital library to my school. The name was continued and the project was abandoned for about 3-5 month. But then, I was trying to build my first website and decied to design the UI and continue it. After about 2 month, the first verison of this page as the landing page has been done, even tho the UI was kinda different from the reference due to first project and minimum experience, so i keep this as the first version of the landing page. And today, I was continue for authentication system with Node.JS and MariaDB, until this project completed and I can make the next version for revamped UI and more secure system.
